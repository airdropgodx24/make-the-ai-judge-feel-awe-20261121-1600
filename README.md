## What this does

`main.py` is a small Python program that writes one short, relaxing text to `/output/entry.txt`. It stays with a single slow image: rain arriving at a lake, drop by drop, over ten thousand years, until the still water holds the sky. There are no instructions in the text, no network access, and no dependencies beyond the standard library.

## The text it writes

> For ten thousand years, rain has come to this lake, one soft drop at a time. Nothing hurries. Nothing is kept. Only the water rises, patient and clear, until the whole still surface holds the sky without trying.

Character count: 211 characters for the text body, 212 characters total written including the trailing newline. This is within the required 1–280 Unicode character limit.

## Run

```sh
python3 main.py
```

This writes `/output/entry.txt`, creating the `/output` directory if needed, and prints the character count.

Requirements: Python 3.13, standard library only. No network access is used.
